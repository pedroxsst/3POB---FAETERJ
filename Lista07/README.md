# Lista 07 — Herança e polimorfismo

Exercícios com herança, sobrescrita de métodos, uso de `super` e polimorfismo.

## Exercícios

| Exercício | Tema | Conteúdo |
| --- | --- | --- |
| [01](Exercicio01/Main.java) | Veículos | Herança, construtor da superclasse e sobrescrita |
| [02](Exercicio02/Main.java) | Folha de pagamento | Cálculo polimórfico de salários |
| [03](Exercicio03/Main.java) | Notificações | Polimorfismo em parâmetros de métodos |
| [04](Exercicio04/Main.java) | Figuras geométricas | Sobrescrita do cálculo de área |
| [05](Exercicio05/Main.java) | Contas bancárias | Regras de saque especializadas |

## Como executar

Com o JDK instalado, abra o terminal na raiz do repositório.

Para compilar e executar o exercício 1:

```sh
javac -encoding UTF-8 Lista07/Exercicio01/*.java
java -cp . Lista07.Exercicio01.Main
```

Para outro exercício, troque `Exercicio01` por `Exercicio02`, `Exercicio03`, `Exercicio04` ou `Exercicio05` nos dois comandos.
