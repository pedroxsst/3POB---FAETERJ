# Lista 09 — Abstract e implements

Exercícios com interfaces, classes abstratas, múltiplos contratos e combinação de `extends` com `implements`.

## Exercícios

| Exercício | Tema | Conteúdo |
| --- | --- | --- |
| [01](Exercicio01/Main.java) | Meios de pagamento | Interface e polimorfismo por contrato |
| [02](Exercicio02/Main.java) | Formas | Classe e método abstrato |
| [03](Exercicio03/Main.java) | Usuários | Implementação de uma ou mais interfaces |
| [04](Exercicio04/Main.java) | Contas bancárias | Taxação obrigatória em subclasses |
| [05](Exercicio05/Main.java) | Itens tributáveis | Classe abstrata junto com interface |

## Como executar

Com o JDK instalado, abra o terminal na raiz do repositório.

Para compilar e executar o exercício 1:

```sh
javac -encoding UTF-8 Lista09/Exercicio01/*.java
java -cp . Lista09.Exercicio01.Main
```

Para outro exercício, troque `Exercicio01` por `Exercicio02`, `Exercicio03`, `Exercicio04` ou `Exercicio05` nos dois comandos.
