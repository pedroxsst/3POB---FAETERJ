# Lista 02 — Estruturas condicionais

Exercícios com if, else, comparações e operadores lógicos para tomar decisões.

## Exercícios

| Exercício | Tema | Conteúdo |
| --- | --- | --- |
| [01](Exercicio01/Main.java) | Par ou ímpar | Resto da divisão e if/else |
| [02](Exercicio02/Main.java) | Verificação de maioridade | Cálculo de idade e comparação |
| [03](Exercicio03/Main.java) | Maior de três números | Comparações e condicionais aninhadas |
| [04](Exercicio04/Main.java) | Situação do aluno | Aprovação, recuperação ou reprovação |
| [05](Exercicio05/Main.java) | Classificação de triângulos | Validação dos lados e classificação |

## Como executar

Com o JDK instalado, abra o terminal na **raiz do repositório**, onde ficam as pastas Lista01 a Lista06.

Para compilar e executar o exercício 1:

```sh
javac -encoding UTF-8 Lista02/Exercicio01/Main.java
java -cp . Lista02.Exercicio01.Main
```

Para outro exercício, troque Exercicio01 por Exercicio02, Exercicio03, Exercicio04 ou Exercicio05 nos dois comandos. Cada pasta tem seu próprio Main.java, separado por pacote.

Nos programas que recebem números decimais, use o separador aceito pela configuração regional do Java: vírgula ou ponto.

## Observações

Na solução atual do exercício 2, o ano de referência está fixado em 2026. No exercício 4, a aprovação ocorre com média maior ou igual a 7.
