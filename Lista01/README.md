# Lista 01 — Entrada de dados e operações básicas

Exercícios com leitura pelo Scanner, variáveis, operações aritméticas e formatação de resultados.

## Exercícios

| Exercício | Tema | Conteúdo |
| --- | --- | --- |
| [01](Exercicio01/Main.java) | Média de três notas | Leitura de decimais e média aritmética |
| [02](Exercicio02/Main.java) | Área e perímetro de um retângulo | Operações com base e altura |
| [03](Exercicio03/Main.java) | Conversão de Celsius para Fahrenheit | Fórmula de conversão e formatação |
| [04](Exercicio04/Main.java) | Salário líquido com desconto fixo | Cálculo de salário e porcentagem |
| [05](Exercicio05/Main.java) | Conversão de segundos | Divisão inteira e resto da divisão |

## Como executar

Com o JDK instalado, abra o terminal na **raiz do repositório**, onde ficam as pastas Lista01 a Lista06.

Para compilar e executar o exercício 1:

```sh
javac -encoding UTF-8 Lista01/Exercicio01/Main.java
java -cp . Lista01.Exercicio01.Main
```

Para outro exercício, troque Exercicio01 por Exercicio02, Exercicio03, Exercicio04 ou Exercicio05 nos dois comandos. Cada pasta tem seu próprio Main.java, separado por pacote.

Nos programas que recebem números decimais, use o separador aceito pela configuração regional do Java: vírgula ou ponto.
