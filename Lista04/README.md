# Lista 04 — Vetores

Exercícios com arrays de uma dimensão, índices, busca de elementos e percursos com laços.

## Exercícios

| Exercício | Tema | Conteúdo |
| --- | --- | --- |
| [01](Exercicio01/Main.java) | Leitura em ordem inversa | Vetor de cinco inteiros |
| [02](Exercicio02/Main.java) | Maior, menor e suas posições | Comparação de dez valores e índices |
| [03](Exercicio03/Main.java) | Média da turma | Oito notas e identificação das notas acima da média |
| [04](Exercicio04/Main.java) | Busca linear | Busca de um valor e sua primeira posição |
| [05](Exercicio05/Main.java) | Separação de pares e ímpares | Distribuição de dez números em dois vetores |

## Como executar

Com o JDK instalado, abra o terminal na **raiz do repositório**, onde ficam as pastas Lista01 a Lista06.

Para compilar e executar o exercício 1:

```sh
javac -encoding UTF-8 Lista04/Exercicio01/Main.java
java -cp . Lista04.Exercicio01.Main
```

Para outro exercício, troque Exercicio01 por Exercicio02, Exercicio03, Exercicio04 ou Exercicio05 nos dois comandos. Cada pasta tem seu próprio Main.java, separado por pacote.

Nos programas que recebem números decimais, use o separador aceito pela configuração regional do Java: vírgula ou ponto.
