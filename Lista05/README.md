# Lista 05 — Matrizes

Exercícios com arrays de duas dimensões, linhas, colunas e laços aninhados.

## Exercícios

| Exercício | Tema | Conteúdo |
| --- | --- | --- |
| [01](Exercicio01/Main.java) | Leitura e exibição de uma matriz | Matriz 3 × 3 em formato de grade |
| [02](Exercicio02/Main.java) | Soma da diagonal principal | Matriz 4 × 4 e índices iguais |
| [03](Exercicio03/Main.java) | Maior elemento e sua localização | Busca em uma matriz 3 × 4 |
| [04](Exercicio04/Main.java) | Soma por linha | Matriz 4 × 3 e vetor de somas |
| [05](Exercicio05/Main.java) | Matriz transposta | Conversão de uma matriz 2 × 3 em 3 × 2 |

## Como executar

Com o JDK instalado, abra o terminal na **raiz do repositório**, onde ficam as pastas Lista01 a Lista06.

Para compilar e executar o exercício 1:

```sh
javac -encoding UTF-8 Lista05/Exercicio01/Main.java
java -cp . Lista05.Exercicio01.Main
```

Para outro exercício, troque Exercicio01 por Exercicio02, Exercicio03, Exercicio04 ou Exercicio05 nos dois comandos. Cada pasta tem seu próprio Main.java, separado por pacote.

Nos programas que recebem números decimais, use o separador aceito pela configuração regional do Java: vírgula ou ponto.
