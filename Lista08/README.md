# Lista 08 — Sobrecarga de construtores e encapsulamento

Exercícios com atributos privados, getters, setters, validações e sobrecarga de construtores.

## Exercícios

| Exercício | Tema | Conteúdo |
| --- | --- | --- |
| [01](Exercicio01/Main.java) | Produto | Sobrecarga de construtores e validação de preço e estoque |
| [02](Exercicio02/Main.java) | Conta bancária | Saldo protegido e número de conta imutável |
| [03](Exercicio03/Main.java) | Retângulo | Validação pelos setters desde o construtor |
| [04](Exercicio04/Main.java) | Carro | Operações de aceleração e frenagem |
| [05](Exercicio05/Main.java) | Funcionário | Regra de aumento salarial no setter |

## Como executar

Com o JDK instalado, abra o terminal na raiz do repositório.

Para compilar e executar o exercício 1:

```sh
javac -encoding UTF-8 Lista08/Exercicio01/*.java
java -cp . Lista08.Exercicio01.Main
```

Para outro exercício, troque `Exercicio01` por `Exercicio02`, `Exercicio03`, `Exercicio04` ou `Exercicio05` nos dois comandos.
